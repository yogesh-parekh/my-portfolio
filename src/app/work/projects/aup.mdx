## Overview

Managing the full lifecycle of over 700 internal applications across multiple teams, business units, and compliance domains required more than tools — it needed a platform that enabled structured workflows, stakeholder accountability, and secure data flow.

To address this, our team built the Application Universe, an internal Application Lifecycle Management (ALM) platform designed to orchestrate everything from app creation and stakeholder approvals to lifecycle updates, integrations, and access control.

As Team Lead, I was responsible for driving architecture, feature planning, cross-team coordination, and the secure integration of platform services.

## Key Features

- Build a platform for centralized ALM across 700+ applications
- Enable role-based, field-level access controls for app data and approvals
- Automate multi-stage workflows triggered by form changes or lifecycle status
- Push updates to Google Sheets for reporting and transparency
- Provide secure APIs for other teams to consume platform data
- Integrate with SSO (Okta) and a token-based auth system with auto-renewal
- Log all activity for audit and compliance tracking

## My Role as Team Lead

- Led a cross-functional team of engineers to deliver key platform features through agile, iterative development
- Worked closely with the platform architect to shape the overall system design and contributed to architectural decisions
- Designed and implemented the workflow orchestration engine for field-triggered approvals and status transitions
- Built the field-level permission system, enabling precise control over who can edit or approve specific sections
- Integrated Google Sheets automation to support live reporting across departments
- Oversaw the secure JWT token renewal mechanism, minimizing manual effort and downtime
- Directed and validated the integration with Okta SSO, ensuring seamless authentication and role-based access
- Led development of the API layer, onboarding external teams and ensuring secure, scalable access
- Set up audit logging to AWS CloudWatch, enabling full traceability of user and system actions
- Acted as a bridge between engineering, platform security, compliance, and business stakeholders

## Technologies Used

- **Languages**: Python, React.js
- **Cloud Stack**: AWS Lambda, SQS, API Gateway, Secrets Manager
- **Authentication**: Okta (SSO), JWT Tokens
- **Automation**: Google Sheets API, Email Triggers (AWS SES)
- **Monitoring**: AWS CloudWatch, internal audit trail system

## Key Platform Features

- **Role-Based Field Permissions** – Edit/approve restrictions per stakeholder
- **Multi-Workflow Engine** – Field-triggered logic with multiple approvers
- **Secure Token Authentication** – Auto-renewed every 90 days
- **SSO Integration** – Okta-based login and role enforcement
- **Email Notifications** – Event-based communication to concerned users
- **Data Sync** – Real-time Google Sheets integration
- **Audit & Logging** – Every change traceable in CloudWatch
