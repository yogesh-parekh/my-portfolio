## Overview

To manage enterprise-wide access efficiently, we built a scalable RBAC (Role Based Access Control) system that integrates with 150+ SaaS and internal applications. It automates role assignments, provisioning, de-provisioning, and compliance enforcement. I was a key contributor to the architecture, integration, and provisioning logic.

## Key Features

- **Business Role Definition**: Managers define app-level permissions.
- **Dynamic Provisioning**: Automatic access assignment/removal based on roles.
- **Contextual Checks**: Decisions based on compliance rules, sensitivity.
- **Dashboards**: Visual access tracking and status updates.
- **Automation** Email triggers, retries, escalations, and ticket creation.

## Technologies Used

- **Languages**: Python, React.js
- **Infra**: AWS Lambda, SQS, API Gateway
- **Integrations**: Okta, Jira API, Slack
- **Storage**: Secrets Manager, S3
- **Monitoring**: CloudWatch, Dashboards

## My Contributions

- Collaborated in end-to-end design discussions and implementation.
- Built connectors and automated workflows for Jira-driven access provisioning.
- Helped implement compliance logic for sensitive permission checks.
- Integrated with Okta, Jira, internal databases, and dashboards.
- Worked on alerting, ticket creation, email notifications, and retry handling.

## Outcomes and Impact

- Provisioned thousands of users automatically across 150+ apps.
- Reduced provisioning turnaround time from 2 days to minutes.
- 100% audit trail compliance for all provisioning workflows.
- Prevented 200+ risky provisioning actions through smart sensitivity checks.
